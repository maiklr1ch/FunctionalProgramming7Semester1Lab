# FunctionalProgramming7Semester1Lab
## Розклад роботи дисплейних класів факультету (Haskell + MySQL)

Репозиторій містить лабораторну роботу №1 з курсу «Функціональне програмування» за 7 семестр.

Консольна інформаційна система: введення й коригування даних про класи, робочі місця,
користувачів, викладачів, розклад занять, час вільного доступу та завантаженість.

## Запуск

```bash
# 1. Бібліотеки для пакетів mysql / mysql-simple (Ubuntu/Debian)
sudo apt install libmysqlclient-dev libpcre3-dev pkg-config

# 2. БД: 8 таблиць + тестові дані (MySQL 8)
mysql -u root -p < schema.sql

# 3. Параметри БД
export DB_HOST=localhost DB_PORT=3306
export DB_USER=root DB_PASSWORD=secret
export DB_NAME=display_classes

# 4. Збірка і запуск
cabal update
cabal run display-classes
```

## Структура БД (8 таблиць)

| Таблиця        | Вміст                                                       | Зв'язки                                   |
|----------------|-------------------------------------------------------------|-------------------------------------------|
| `classrooms`   | дисплейні класи (назва, корпус, місткість)                  | -                                         |
| `workstations` | робочі місця (інв. номер, характеристики, стан)             | `classrooms`                            |
| `users`        | користувачі (логін, ПІБ, роль, e-mail, активність)          | -                                         |
| `teachers`     | дані викладачів (кафедра, посада)                           | `users` (1:1)                           |
| `subjects`     | дисципліни                                                  | -                                         |
| `schedule`     | планові заняття (день, час, група)                          | `classrooms`, `teachers`, `subjects`    |
| `free_access`  | інтервали вільного доступу до класів                        | `classrooms`                            |
| `usage_log`    | журнал сеансів за робочими місцями (основа для завантаженості) | `workstations`, `users`, `schedule`  |

## Класи типів та їхні екземпляри

| Клас          | Призначення                                              | Екземпляри |
|---------------|----------------------------------------------------------|------------|
| `Persistent`  | як сутність зберігається в таблиці; універсальний CRUD   | Classroom, Workstation, User, Teacher, Subject, Lesson, FreeSlot, Session |
| `Promptable`  | діалог введення / виправлення запису    | ті самі 8 |
| `Validatable` | чиста перевірка полів                                    | ті самі 8 |
| `Checked`     | перевірки цілісності через БД | ті самі 8 |
| `Pretty`      | подання значення рядком                                  | ті самі 8 |
| `Enumerated`  | перелік <-> MySQL `ENUM` <-> український підпис              | Role, WsStatus, SessionKind, WeekDay |
| `Input`       | розбір і показ одного поля форми                         | Text, Int, Bool, TimeOfDay, UTCTime, `Maybe a`, Role, WsStatus, SessionKind, WeekDay |
| `Tabular`     | рядок звіту -> вирівняна таблиця                          | ScheduleRow, FreeAccessRow, FreeNowRow, ClassLoadRow, WsLoadRow, ActiveSession |

Крім того, сутності й рядки звітів реалізують `QueryResults`, а типи-переліки - `Param` та `Result` з `mysql-simple`.
Функція `crudMenu` (модуль `Menu`) одна на всі таблиці: їй потрібні лише екземпляри `Persistent`, `Promptable`,
`Validatable`, `Checked`.

## Правила цілісності (клас `Checked`)

- заняття не перетинаються за часом ні в класі, ні у викладача, ні в групи;
- заняття не потрапляє на години вільного доступу, і навпаки; інтервали вільного доступу одного класу не перетинаються;
- кількість робочих місць у класі ≤ його місткості;
- до таблиці `teachers` можна додати лише користувача з роллю «викладач»;
- на одному робочому місці не може бути двох сеансів одночасно; заняття має проходити в класі цього місця;
- початок сеансу: місце має бути в стані «працює», а для вільного доступу - поточний час усередині інтервалу.

Помилки MySQL (дублікат, порушення зовнішнього ключа) перехоплюються й показуються зрозумілим повідомленням.

## Завантаженість

Звіт «Завантаженість дисплейних класів»: за розкладом - години занять і вільного доступу на тиждень та відсоток від
60 год (пн–пт, 08:00–20:00; константа `weekCapacityHours` у `Reports.hs`); фактична - кількість сеансів і місце-годин
за останні N днів із `usage_log`. Звіт «Завантаженість робочих місць» - сеанси й години по кожному ПК.
